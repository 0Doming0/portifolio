# Vitor Domingos — Portfolio

Static HTML/CSS portfolio prepared for Cloudflare Pages.

## What you need to edit

Open `index.html` and replace these placeholders:

- `YOUR_LINKEDIN_URL`
- `YOUR_EMAIL`
- `YOUR_DOMING_PROJECT_URL`
- `YOUR_DOMING_GITHUB_URL`
- `YOUR_SKYDUNGEON_GAME_URL`
- `YOUR_SKYDUNGEON_GITHUB_URL`
- `YOUR_MARKETRIPPLE_URL`
- `YOUR_MARKETRIPPLE_GITHUB_URL`
- `YOUR_AI_STUDY_PROJECT_URL`
- `YOUR_INVESTMENT_GITHUB_URL`

If a project has no public demo, remove that link or point only to its public repository/case page.

## Cloudflare Pages

1. Open Cloudflare Dashboard.
2. Go to **Workers & Pages**.
3. Create a Pages project and connect this GitHub repository.
4. Select the `main` branch.
5. This is a static site and does not require a framework.
6. Use the repository root as the site output.
7. Deploy.

The site only depends on `index.html` and `styles.css`.

## Local preview

You can simply open `index.html` in a browser, or serve the folder with any static HTTP server.
