# Vitor Domingos — Portfolio

Lightweight static portfolio written in English and prepared for Netlify deployment.

## Links to configure

Open `index.html` and replace the remaining placeholders:

- `YOUR_LINKEDIN_URL`
- `YOUR_EMAIL`
- `YOUR_DOMING_PROJECT_URL`
- `YOUR_SKYDUNGEON_GAME_URL`
- `YOUR_MARKETRIPPLE_URL`
- `YOUR_SSTUDE_PROJECT_URL`

Public GitHub repository links for Doming and SkyDungeon are already included.

If a project does not have a public demo, keep the portfolio case description and omit the external link rather than linking to a broken or private page.

## Netlify deployment

This project is plain HTML/CSS and requires no build step.

1. Open Netlify.
2. Choose **Add new project** → **Import an existing project**.
3. Connect GitHub and select the `0Doming0/portifolio` repository.
4. Select the `main` branch.
5. Leave the build command empty.
6. Use `.` as the publish directory if Netlify asks for one.
7. Deploy.

The site only depends on `index.html` and `styles.css`.

## Local preview

Open `index.html` directly in a browser or serve the folder with any static HTTP server.

## Portfolio language

The recruiter-facing portfolio and project documentation are written in English. Some historical product interfaces may remain in Portuguese when they are preserved as original evidence of products built for the Brazilian market.
